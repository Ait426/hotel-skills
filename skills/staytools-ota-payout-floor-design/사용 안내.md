# 사용 안내 — staytools-ota-payout-floor-design

OTA 할인 사다리를 입금가 하한 제약 아래서 설계. 버전 1.2.0.

이 배포본은 특정 숙소의 식별 정보와 고정값을 뺀 범용판입니다. 본문과 양식의 숫자는 형식 예시이며
어느 OTA의 공통 계약 조건도 아닙니다. **자기 숙소의 값을 넣어 쓰세요.**

## 설치

- **Claude (Cowork·채팅)**: 사용자 지정 → 스킬 → 추가 → 스킬 업로드에서 이 ZIP을 선택합니다.
  새 작업에서 `/staytools-ota-payout-floor-design` 을 고르거나 "staytools-ota-payout-floor-design 스킬로 …"라고 요청합니다.
- **Claude Code**: 압축을 풀어 나온 폴더를 프로젝트의 `.claude/skills/` (또는 `~/.claude/skills/`) 아래에 넣습니다.

## 준비할 입력

- 판매가
- 입금 계수(정산 확인값인지 추정인지)
- 요금제 배수와 할인 구조(가산/곱셈, 중복 규칙)
- 입금가 하한과 헤드라인 목표

빠진 값은 스킬이 되묻거나 "미확인"으로 표시합니다. 임의로 채우지 않습니다.

## 들어 있는 파일

- `SKILL.md` — 판정 순서 · 부등식 · 보고 형식

## 범위와 주의

채널 화면을 읽지 않는 계산·설계 스킬입니다. 실측 확인은 소비자 페이지에서 따로 해야 합니다.

- 투숙객·고객의 이름·연락처·예약번호는 입력 자료에서 지우고 주세요. 스킬도 결과물에 남기지 않습니다.
- 로그인과 계정 인증은 사용자가 직접 합니다. 비밀번호·인증 토큰을 스킬이나 대화에 넣지 마세요.
- 계산값은 실제 정산 확정액이 아닙니다. 정산서·예약 결제 내역으로 확인하세요.
- OTA 화면과 정책은 바뀔 수 있습니다. 화면 절차가 맞지 않으면 숫자를 믿지 말고 다시 확인하세요.
