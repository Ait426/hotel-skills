# 사용 안내 — staytools-sales-analysis

PMS 예약 내보내기 엑셀로 월간 채널별 매출분석 엑셀을 만듭니다. 버전 1.0.0.

이 배포본은 특정 숙소의 식별 정보와 고정값을 뺀 범용판입니다. 수수료·쿠폰 부담·부가세 기준은 어느 OTA의 공통 계약 조건도 아닙니다.
**자기 숙소의 값을 넣어 쓰세요.**

## 설치

- **Claude (Cowork·채팅)**: 사용자 지정 → 스킬 → 추가 → 스킬 업로드에서 이 ZIP을 선택합니다.
  새 작업에서 `/staytools-sales-analysis` 를 고르거나 "staytools-sales-analysis 스킬로 …"라고 요청합니다.
- **Claude Code**: 압축을 풀어 나온 폴더를 프로젝트의 `.claude/skills/` (또는 `~/.claude/skills/`) 아래에 넣습니다.

## 준비할 입력

- PMS 예약 내보내기 엑셀(.xlsx). 기간은 분석 월의 전달 말일 ~ 다음 달 1일
- 열 매핑 JSON(YFlux는 기본 프리셋, 다른 PMS는 양식을 채움)
- 숙소명, 객실 타입 목록, 기업·기관 거래처 이름
- 채널별 금액 기준(입금가/판매가/실수령)과 수수료·쿠폰 부담·부가세 처리 기준
- (선택) 전달 집계 파일: 전월 대비용
- (선택) PMS 청구·매출 보고서 합계: 결과 대조용

빠진 값은 스킬이 되묻거나 "확인 필요"로 표시합니다. 임의로 채우지 않습니다.

## 실행

```
python scripts/sales_report.py --input 예약.xlsx --config mapping.json --out 분석.xlsx --month YYYY-MM
```

필요한 패키지는 `pandas`, `numpy`, `openpyxl` 입니다. 없으면 `pip install pandas numpy openpyxl` 로 설치합니다.
Python 3.14, pandas 3.0, numpy 2.4, openpyxl 3.1 에서 실행을 확인했습니다.

## 들어 있는 파일

- `SKILL.md` — PMS 함정 · 기간과 매출 기준 · 입력 형식 · 결과 대조 절차 · 개인정보 규칙
- `hotel-profile.example.md` — 숙소 프로필 양식
- `scripts/sales_report.py` — 분석 엑셀을 만드는 스크립트
- `scripts/mapping-yflux.json` — YFlux 기본 프리셋
- `scripts/mapping-template.json` — 다른 PMS용 열 매핑 양식

## 범위와 주의

YFlux 프리셋은 한 숙소의 실제 내보내기로 원본 도구와 채널별 건수·매출·합계를 대조했습니다. **YFlux 외 PMS는 미검증입니다.** 가상 데이터로 실행만 확인했으며, 결과에 「미검증 매핑」이 표시됩니다.
PMS 보고서 합계와 먼저 맞춘 뒤에 해석하세요.

- 투숙객·고객의 이름·연락처는 입력 자료에 넣지 마세요. 스크립트는 매핑한 열만 읽고, 개인정보로 보이는 열을 매핑하면 멈춥니다.
- 결과 엑셀의 [원본]·[청구대조] 탭에는 예약번호와 객실 호수가 있습니다. 외부에 공유할 때는 이 탭을 빼세요.
- 재방문 분석은 들어 있지 않습니다. 요청하면 건수·비율만 다루고 개인 식별 정보는 출력하지 않습니다.
- 예정일 보정·판매 객실·국적·청구 보고서 자료는 PMS에서 직접 받아 JSON으로 넣어야 합니다. 자동 수집은 들어 있지 않습니다. 없으면 해당 항목이 빠지고 결과에 경고가 적힙니다.
- 수수료·쿠폰 부담·부가세 입력값은 [채널구분표]에 표시만 됩니다. 분석 금액은 PMS에 들어온 금액 그대로이며 실제 정산액이 아닙니다.
- 로그인과 계정 인증은 사용자가 직접 합니다. 비밀번호·인증 토큰을 스킬이나 대화에 넣지 마세요.
- PMS 화면과 내보내기 형식은 바뀔 수 있습니다. 합계가 맞지 않으면 숫자를 믿지 말고 다시 확인하세요.
