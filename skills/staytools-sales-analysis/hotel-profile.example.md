# 숙소 프로필 — 매출분석 (양식)

이 파일을 `hotel-profile.md` 로 복사해 **자기 숙소의 값**으로 채운다. 아래 값은 가상 숙소의 형식 예시다.
모르는 칸은 비워 두고 "미확인"이라고 적는다. 비밀번호·예약번호·투숙객 정보는 적지 않는다.

## 기본

| 항목 | 값 |
|---|---|
| 숙소명 | (예) 샘플 스테이 |
| PMS | (예) YFlux / 그 밖의 PMS 이름 |
| 매핑 파일 | (예) mapping.json |
| 기준 월 | YYYY-MM |
| 월 매출의 기준 | (예) PMS 청구 보고서 / 체크인 기준 예약 금액 |
| 달을 나누는 기준 | (예) 예정 체크인일 / PMS 화면 기준 |
| 조회·확정일 | YYYY-MM-DD |

## 내보내기 열의 뜻

| 질문 | 답 | 확인 방법 |
|---|---|---|
| 금액 열은 받은 돈인가, 예약 금액인가 | (예) 받은 돈, 잔액 열이 따로 있음 | 잔액 있는 예약 1~2건 |
| 체크인 열은 예정일인가, 실제 입실 시각인가 | (예) 실제 입실 시각 | 새벽 입실 예약 1~2건 |
| 객실 타입 열은 판매 객실인가, 배정 방인가 | (예) 배정 방 | 업그레이드한 예약 1~2건 |
| 취소·노쇼 표시 값 | (예) 취소, 노쇼 | 예약 상태 열 |
