# 사용 안내 — staytools-expedia-payout

익스피디아 숙소 조사 · 입금가 계산 · 달력요금 역산 · 프로모션 판정 · 숙소 점검 · HTML 콘솔 생성. 버전 1.6.1.

이 배포본은 특정 숙소의 식별 정보와 고정값을 뺀 범용판입니다. 본문과 양식의 숫자는 형식 예시이며
어느 OTA의 공통 계약 조건도 아닙니다. **자기 숙소의 값을 넣어 쓰세요.**

## 설치

- **Claude (Cowork·채팅)**: 사용자 지정 → 스킬 → 추가 → 스킬 업로드에서 이 ZIP을 선택합니다.
  새 작업에서 `/staytools-expedia-payout` 을 고르거나 "staytools-expedia-payout 스킬로 …"라고 요청합니다.
- **Claude Code**: 압축을 풀어 나온 폴더를 프로젝트의 `.claude/skills/` (또는 `~/.claude/skills/`) 아래에 넣습니다.

## 준비할 입력

- 익스피디아 숙소 ID(htid)
- 달력요금(부가세 포함)과 요금세트 규칙
- 기본 보수율, 엑셀러레이터 요율(최근 예약 결제 내역 기준)
- 프로모션 목록(비회원/회원 할인율, 조건)과 목표 입금가

빠진 값은 스킬이 되묻거나 "미확인"으로 표시합니다. 임의로 채우지 않습니다.

## 들어 있는 파일

- `SKILL.md` — 시작 절차 · 작업 순서 · 판단 규칙
- `references/` — 숙소 점검 · 공식과 프로모션 · 입금가 실측 · 화면 지도 · 요금세트와 예약 연동
- `scripts/payout.py` — 입금가 계산기 (Python 3, 외부 패키지 없음)
- `scripts/build_console.py` — property.json → HTML 콘솔 한 장
- `scripts/snippets.js` — 포털에서 값을 읽고 입력하는 브라우저 스니펫 (점검 화면 읽기 포함)
- `assets/property.example.json` — 입력 양식
- `properties/example-hotel-00000000.json` — 가상 숙소의 채워진 예시
- `hotel-profile.example.md` — 숙소 프로필 양식

## 범위와 주의

파트너센트럴 화면 조작은 브라우저 조작 도구가 있는 환경에서만 됩니다. 도구가 없으면 가져온 자료로 계산과 HTML 콘솔 생성까지 합니다. 실입금은 예약 결제 내역으로만 확정합니다.

- 투숙객·고객의 이름·연락처·예약번호는 입력 자료에서 지우고 주세요. 스킬도 결과물에 남기지 않습니다.
- 로그인과 계정 인증은 사용자가 직접 합니다. 비밀번호·인증 토큰을 스킬이나 대화에 넣지 마세요.
- 계산값은 실제 정산 확정액이 아닙니다. 정산서·예약 결제 내역으로 확인하세요.
- OTA 화면과 정책은 바뀔 수 있습니다. 화면 절차가 맞지 않으면 숫자를 믿지 말고 다시 확인하세요.
