# 사용 안내 — staytools-trip-payout

트립닷컴 숙소 조사 · 입금가 계산 · 판매가 역산 · 프로모션 판정 · 재판매 구분 · 숙소 점검 · HTML 콘솔. 버전 1.4.0.

이 배포본은 특정 숙소의 식별 정보와 고정값을 뺀 범용판입니다. 본문과 양식의 숫자는 형식 예시이며
어느 OTA의 공통 계약 조건도 아닙니다. **자기 숙소의 값을 넣어 쓰세요.**

## 설치

- **Claude (Cowork·채팅)**: 사용자 지정 → 스킬 → 추가 → 스킬 업로드에서 이 ZIP을 선택합니다.
  새 작업에서 `/staytools-trip-payout` 을 고르거나 "staytools-trip-payout 스킬로 …"라고 요청합니다.
- **Claude Code**: 압축을 풀어 나온 폴더를 프로젝트의 `.claude/skills/` (또는 `~/.claude/skills/`) 아래에 넣습니다.

## 준비할 입력

- 트립닷컴 호텔 계약 ID와 고객 페이지 호텔 ID
- 요금 모드(판매가 입력 방식)와 객실·요금제별 달력 판매가
- 수수료율, 환불불가 파생 배수, 인원별 요금 규칙
- 프로모션 목록(OFF 칸의 할인율, 적용 국가, 대상 객실·요금제)과 회원 할인
- 최근 예약의 지불 정보(할인 내역, 지급액)
- 목표 입금가와 어느 경로 기준인지

빠진 값은 스킬이 되묻거나 "미확인"으로 표시합니다. 임의로 채우지 않습니다.

## 들어 있는 파일

- `SKILL.md` — 인자 처리 · 요청 분류 · 전체 흐름 · 판정과 검증 순서
- `references/` — 공식·할인 구조(`pricing.md`), 입금가 확인·데이터 수집(`measure.md`), 화면 지도·재판매 구분·함정(`portal-map.md`), 숙소 점검(`audit.md`), WINGSCMS 절차(`cms.md`)
- `scripts/payout.py` — 입금가 · 역산 · 복원 · 예약 대조 · 경로별 표 계산기
- `scripts/build_console.py` — 조사 결과로 HTML 콘솔을 만드는 도구
- `scripts/snippets.js` — 브라우저에서 쓰는 입력 · 재판매 판별 · 지불 정보 읽기 · 점검 화면 읽기
- `assets/property.example.json` — 콘솔 입력 빈 양식
- `properties/example-hotel-00000000.json` — 가상 숙소 예시
- `hotel-profile.example.md` — 숙소 프로필 양식

계산기와 콘솔에는 Python 3가 필요합니다. 추가 패키지는 없습니다. 생성한 HTML은 파일 하나로 열립니다.

## 범위와 주의

eBooking 화면 조회는 브라우저 조작 도구가 있는 환경에서만 됩니다. 실입금은 예약 상세의 지급액으로만 확정합니다.

- 판매가 입력 방식에서만 공식을 확인했습니다. 넷가·후불·VCC 계약은 미검증입니다.
- 캠페인과 회원 할인의 중복, 프로모션 적용 기준, 부가세 처리 등은 `SKILL.md`에 "확인 필요"로 표시돼 있습니다. 숙소마다 실예약으로 확인하세요.
- 투숙객·고객의 이름·연락처·예약번호는 입력 자료에서 지우고 주세요. 스킬도 결과물에 남기지 않습니다.
- 로그인·결제·최종 저장은 사용자가 직접 합니다. 비밀번호·인증 토큰을 스킬이나 대화에 넣지 마세요.
- 계산값은 실제 정산 확정액이 아닙니다. 정산서·예약 지급액으로 확인하세요.
- OTA 화면과 정책은 바뀔 수 있습니다. 화면 절차가 맞지 않으면 숫자를 믿지 말고 다시 확인하세요.
