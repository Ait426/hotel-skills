# 사용 안내 — staytools-guest-mix

예약 데이터로 손님 유형을 나누고, 비는 날·꽉 찬 날을 찾아, 손님에게 맞는 OTA 설정을 추천합니다. 버전 1.0.0.
추천마다 각 OTA의 입금가 하한을 지키는지 검산합니다.

이 배포본에는 특정 숙소의 값이 없습니다. 예시 파일은 전부 가상 숙소입니다.
**자기 숙소의 객실 수와 OTA 설정값을 넣어 쓰세요.**

## 설치

- **Claude (Cowork·채팅)**: 사용자 지정 → 스킬 → 추가 → 스킬 업로드에서 이 ZIP을 선택합니다.
  새 작업에서 `/staytools-guest-mix` 를 고르거나 "staytools-guest-mix 스킬로 …"라고 요청합니다.
- **Claude Code**: 압축을 풀어 나온 폴더를 프로젝트의 `.claude/skills/` (또는 `~/.claude/skills/`) 아래에 넣습니다.

## 준비할 입력

- PMS 예약 내보내기(xlsx 또는 csv). 거래처·체크인·체크아웃·예약 생성일·예약 상태·금액 열 필요
- 객실 타입별 판매 가능 객실 수
- (선택) OTA별 property.json: agoda-audit·booking-rate-ops·expedia-payout·trip-payout 스킬이 만든 파일. 할인 검산에 씀
- (선택) 채널 예약 파일: 트립 주문(국적·요금제), 부킹 예약(인원), 국내 OTA 예약내역(대실·회원등급·쿠폰)
- (선택) 입금가 하한과 대표 판매가: property.json 에 없을 때

빠진 값은 "확인 필요"로 표시합니다. 임의로 채우지 않습니다.

## 실행

```
python scripts/segment_report.py --pms 예약.xlsx --mapping mapping.json --profile profile.json --out-dir 결과 --month YYYY-MM --extra 트립닷컴=trip.csv
```

가상 예시로 먼저 돌려 보려면 스킬 폴더에서 아래를 실행합니다.

```
python scripts/segment_report.py --pms assets/example/pms_example.csv --mapping scripts/mapping-template.json --profile assets/profile.example.json --out-dir 예시결과 --month 2026-03 --extra 트립닷컴=assets/example/trip_example.csv
```

필요한 패키지는 `pandas` 입니다. xlsx 를 읽으려면 `openpyxl` 도 필요합니다(`pip install pandas openpyxl`).
Python 3.14, pandas 3.0 에서 실행을 확인했습니다.

## 결과

- `report.html` — 탭 3개
  - 손님 분포: 유형별 건수·비중·매출·1박 평균·취소율, 채널 교차표
  - 빈 객실: 요일·객실 타입별 점유율, RevPAR
  - 채널별 할 일: 추천, 지금 설정, 할인 전후 입금가, 하한 판정
- `segments.json` — 같은 내용의 데이터

채널 파일은 표본이 적으면 `--extra-start YYYY-MM-DD` 로 더 긴 기간을 봅니다(끝은 분석 기간 끝과 같음). 국적처럼 건수가 적은 축에 씁니다.

## 들어 있는 파일

- `SKILL.md` — 흐름 · 해석 주의 · 개인정보 규칙
- `references/rules.md` — 추천 규칙표와 입금가 검산 공식
- `scripts/segment_report.py` — 분석 스크립트
- `scripts/mapping-template.json` — 열 매핑 양식 (PMS·트립·부킹·국내 OTA)
- `assets/profile.example.json` — 숙소 프로필 양식 (객실 수·OTA 경로·기준값)
- `assets/example/` — 가상 숙소 예약 예시와 OTA property 예시
- `hotel-profile.example.md` — 프로필에 넣을 값 체크리스트

## 범위와 주의

- 가상 데이터로 집계·점유율·입금가를 손으로 검산했습니다. 한 숙소의 실제 YFlux 내보내기로 채널별 유효 예약 건수·취소율을 매출분석(PMS 화면 기준) 결과와 대조해 일치를 확인했습니다. 규칙에 없는 거래처를 묶는 방식이 달라 기업·기관 건수만 다릅니다. **다른 PMS와 채널 파일 형식은 미검증입니다.**
- 추천은 과거 예약 분포에서 나온 제안입니다. 예약이 얼마나 늘지는 예측하지 않습니다.
- 입금가 검산은 대표 판매가 하나로 합니다. 요일·객실별 요금은 각 OTA 콘솔에서 다시 확인하세요.
- 설정을 바꾸지 않습니다. 적용은 각 OTA 화면에서 직접 하세요.
- 예약번호·이름·연락처 열은 매핑하지 마세요. 매핑하면 스크립트가 멈춥니다. 결과 파일에도 들어가지 않습니다.
- 기기(모바일/PC) 정보는 다루지 않습니다. 국적은 채널 파일에 있을 때만 나옵니다.
