# 숙소 프로필 체크리스트 (staytools-guest-mix)

`assets/profile.example.json` 을 복사해 아래 값을 채운다. 모르는 값은 비워 두고 "확인 필요"로 남긴다.

## 객실
- [ ] 객실 타입별 판매 가능 객실 수. 이름은 PMS 내보내기의 객실 타입 값과 똑같이 적는다.
- [ ] 판매하지 않는 객실(사무실·장기 임대 등)은 뺀다.

## 채널
- [ ] PMS 거래처 값 → 채널 이름 규칙(매핑 `pms.channels`)
- [ ] 프로필 `ota` 에 넣을 채널. 이름은 매핑의 channel 과 같아야 한다.
- [ ] 채널별 property.json 경로. 각 OTA 스킬로 조사한 최신 파일을 쓴다.
- [ ] 입금가 하한. 숙소가 정한 값만 넣는다.
- [ ] 대표 판매가: property.json 의 rooms·weekly 와 다를 때만 넣는다.

## 채널 파일 (선택)
- [ ] 트립 주문 내보내기: 국적·요금제·판매가 열 이름
- [ ] 부킹 예약 내보내기: 인원·상태 값(취소가 `C` 인지 등)
- [ ] 국내 OTA 예약내역: 머리글 행 번호, 사용시간 형식("시작 ~ 끝"), 대실 표기

## 기준값 (thresholds)
- [ ] 비는 날·꽉 찬 날 점유율 기준(기본 0.6 / 0.9)
- [ ] 추천 할인 폭(기본 5%p)
- [ ] 표본 최소 건수(기본 20)
