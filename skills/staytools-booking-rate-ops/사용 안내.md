# 사용 안내 — staytools-booking-rate-ops

부킹닷컴 숙소 조사 · 입금가 계산 · 판매가 역산 · 프로모션 판정 · 소비자 페이지 검증 · 숙소 점검 · HTML 콘솔. 버전 1.6.0.

이 배포본은 특정 숙소의 식별 정보와 고정값을 뺀 범용판입니다. 본문과 양식의 숫자는 형식 예시이며
어느 OTA의 공통 계약 조건도 아닙니다. **자기 숙소의 값을 넣어 쓰세요.**

## 설치

- **Claude (Cowork·채팅)**: 사용자 지정 → 스킬 → 추가 → 스킬 업로드에서 이 ZIP을 선택합니다.
  새 작업에서 `/staytools-booking-rate-ops` 을 고르거나 "staytools-booking-rate-ops 스킬로 …"라고 요청합니다.
- **Claude Code**: 압축을 풀어 나온 폴더를 프로젝트의 `.claude/skills/` (또는 `~/.claude/skills/`) 아래에 넣습니다.

## 준비할 입력

- 부킹 숙소 ID와 소비자 페이지 주소
- 객실·요금세트별 판매가, 기준 인원
- 요금제 배수, 타겟 요금·포트폴리오형 프로모션 할인율
- 입금 계수(실예약 정산으로 확인한 값)와 입금가 하한

빠진 값은 스킬이 되묻거나 "미확인"으로 표시합니다. 임의로 채우지 않습니다.

## 들어 있는 파일

- `SKILL.md` — 인자 처리 · 요청 분류 · 전체 흐름 · 절대 규칙
- `references/` — 숙소 점검(`audit.md`), 요금 구조·설계 규칙(`pricing.md`), 소비자 페이지 역산(`measure.md`), 화면 조작·함정(`portal-map.md`), 채널 매니저(`cms.md`), 판매 정지 대응(`suspension.md`)
- `scripts/payout.py` — 입금가 · 역산 · 판매가 복원 · 입금 계수 · 칸별 표 · 최심 칸 계산기
- `scripts/build_console.py` — 조사 결과로 HTML 콘솔을 만드는 도구
- `scripts/snippets.js` — 브라우저에서 쓰는 입력 · 세션 점검 · 화면 이동 · 본문·후기 요약 · 예약 가능 여부 · 요금 행 · 예약 명세서 금액 읽기
- `assets/property.example.json` — 콘솔 입력 빈 양식
- `properties/example-hotel-0000000.json` — 가상 숙소 예시
- `hotel-profile.example.md` — 숙소 프로필 양식

계산기와 콘솔에는 Python 3가 필요합니다. 추가 패키지는 없습니다. 생성한 HTML은 파일 하나로 열립니다.

## 범위와 주의

익스트라넷 화면 조작은 브라우저 조작 도구가 있는 환경에서만 됩니다. 로그인은 사용자가 합니다.

- 투숙객·고객의 이름·연락처·예약번호는 입력 자료에서 지우고 주세요. 스킬도 결과물에 남기지 않습니다.
- 로그인과 계정 인증은 사용자가 직접 합니다. 비밀번호·인증 토큰을 스킬이나 대화에 넣지 마세요.
- 계산값은 실제 정산 확정액이 아닙니다. 정산서·예약 결제 내역으로 확인하세요.
- OTA 화면과 정책은 바뀔 수 있습니다. 화면 절차가 맞지 않으면 숫자를 믿지 말고 다시 확인하세요.
