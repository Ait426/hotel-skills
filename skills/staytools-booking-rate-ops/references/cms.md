# 채널 매니저 — 판매가 변경


### 판매가 (CMS — WINGSCMS 계열을 쓰는 숙소의 예)
- 상품그룹 select는 **JS focus 후 실제 방향키**로 선택. 클릭+방향키는 안 먹는다.
- 화면의 "…를 (부킹 상품그룹) 로 복사 합니다." 안내 문구로 대상 그룹을 확인.
- 창이 작으면 그리드 입력칸이 안 잡힌다 → **1600×1000으로 리사이즈**.
- **저장 판정은 모달로 하지 않는다.** 에러 모달(「시스템 처리중에 문제가 발생했습니다」)이 떴는데 저장된 경우와 안 된 경우가 둘 다 관측됐다.
- 저장 후 **2~3분 기다린 뒤 재조회**한다. 그동안 **재입력·상품그룹 전환 금지** — 처리 중에 겹치면 모달이 뜨고 같은 값을 두 번 넣게 된다.
- 요금ID가 새 값으로 바뀌었으면 저장된 것이다. 2~3분 뒤에도 옛 값이면 그때 다시 넣는다. 최종 판정은 소비자 페이지 역산(`references/measure.md`)으로 한다.

다른 채널 매니저를 쓰면 그 화면의 저장·반영 절차를 프로필에 적어 두고 따른다.
