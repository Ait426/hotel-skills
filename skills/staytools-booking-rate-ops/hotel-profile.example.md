# 숙소 프로필 — 부킹닷컴 (양식)

이 파일을 `hotel-profile.md` 로 복사해 **자기 숙소의 값**으로 채운다. 아래 숫자는 가상 숙소의 형식 예시다.
모르는 칸은 비워 두고 "미확인"이라고 적는다. 비밀번호·투숙객 정보는 적지 않는다.

## 기본

| 항목 | 값 |
|---|---|
| 숙소명 | (예) 샘플 스테이 |
| 부킹 숙소 ID (hotel_id) | (예) 0000000 |
| 소비자 페이지 주소 | `booking.com/hotel/kr/{숙소-슬러그}.ko.html` |
| 채널 매니저 / 부킹용 상품그룹 | (예) WINGSCMS · 「부킹」 그룹 / 없음 |
| 통화 · 부가세 기준 | KRW · 입금가는 부가세 포함 기준 |
| 조회·확정일 | YYYY-MM-DD |

## 버튼 정책

- [ ] 저장 직전에 멈추고 사용자가 누른다 (기본)
- [ ] 에이전트가 저장·적용까지 누른다 (로그인만 사용자가)

## 입금가 기준

| 항목 | 값 | 근거 |
|---|---|---|
| 입금 계수 (입금가 ÷ 노출가) | (예) 0.82 | 최근 실예약 N건의 결제·정산 내역 역산 / 추정 |
| 입금가 하한 | (예) 90,000원 | 운영자 지정 |
| 헤드라인(평시) 목표 입금가 | (예) 100,000원 | 운영자 지정 |

|---|---:|---:|---:|---:|
| (예) 스탠다드 | 200,000 | 230,000 | 260,000 | 2 |
| | | | | |

숙박인원 계수: 기준 인원에서 1명 적을 때마다 (예) −0.05

## 요금세트 규칙

(예) 「내일이 휴무면 FRI, 오늘·내일 모두 휴무면 SAT, 그 외 WEEK」. 휴무 = 토·일 + 공휴일.
일부러 매핑하지 않은 세트: (예) SUN
