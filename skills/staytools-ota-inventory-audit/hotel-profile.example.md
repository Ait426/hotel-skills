# 숙소 프로필 — PMS·OTA 재고 대조 (양식)

이 파일을 `hotel-profile.md` 로 복사해 **자기 숙소의 값**으로 채운다. 아래 내용은 가상 숙소의 형식 예시다.
모르는 칸은 비워 두고 "미확인"이라고 적는다. 비밀번호·투숙객 정보는 적지 않는다.

## 기본

| 항목 | 값 |
|---|---|
| 숙소명 | (예) 샘플 스테이 |
| 시간대 | (예) Asia/Seoul |
| PMS | (예) YFlux PMS / 다른 PMS / 엑셀로 내보낸 잔여표 |
| 대조할 채널 | (예) 야놀자(NOL) 모텔 파트너센터 · 여기어때 모텔 파트너센터 |
| 채널별 숙소 ID | (채널 주소·API에 들어가는 ID) |
| 조사 기본 범위 | 내일부터 30일 (오늘 제외) |

## 조치 권한

- [ ] 조회·조치안까지만 (기본)
- [ ] 분명한 건은 자동 수정 (SKILL.md의 「자동으로 고쳐도 되는 것」 범위)

## PMS 객실 타입

| 객실 타입 | 객실 수 | 오버부킹 허용치 |
|---|---:|---:|
| (예) 스탠다드 | 20 | 0 |
| (예) 디럭스 | 15 | 0 |
| (예) 패밀리 | 5 | 0 |

오버부킹 허용치가 N이면 PMS 잔여 −N까지 정상으로 본다. 적지 않은 타입은 0이다.

## OTA 상품 ↔ PMS 객실 매핑

| OTA 상품 (화면 표기 그대로) | 채널 | PMS 객실 | 비고 |
|---|---|---|---|
| (예) 스탠다드 | A, B | 스탠다드 | |
| (예) 스탠다드 + 조식 1인 | A, B | 스탠다드 | 조식 포함 |
| (예) 디럭스 | A, B | 디럭스 | |
| (예) 랜덤배정 특가 | A, B | 스탠다드 | 랜덤배정 — 다른 타입에 여유가 있으면 열려 있어도 됨 |
| (예) 프런트 전용 패키지 | B | 디럭스 | 상시 마감 |

## 대실 운영 상품

(예) 스탠다드 / 디럭스 — 그 외 상품의 대실 미설정은 정상

## 운영 예외 (정상으로 볼 것)

| 예외 | 대상 상품 | 조건 |
|---|---|---|
| (예) 조식 미운영 | 조식 포함 상품 전부 | 일요일 아침 조식 없음 → 토요일 투숙분 마감이 정상, 열려 있으면 오류 |
| (예) 상시 마감 | 프런트 전용 패키지 | 프런트에서 필요할 때만 연다 |
| (예) 열지 않는 기간 | 전 상품 | (기간) — 운영자가 열지 말라고 한 구간 |

## 상품별 이용시간

| 상품 | 입실 | 퇴실 |
|---|---|---|
| (예) 일반 숙박 상품 | 15:00 | 익일 11:00 |
| (예) 장시간 상품 | 13:00 | 익일 19:00 |
| (예) 대실 | (개시~마감 시각, 이용 N시간) | |

## 요금 기준 (요금제 판정용 · 천 원)

요금 tier 배정 규칙: (예) 「내일이 휴무면 금요일 요금, 오늘·내일 모두 휴무면 토요일 요금, 그 외 평일 요금」

| 채널 | tier | 상품 순서대로 |
|---|---|---|
| (예) A | 평일 | 60 70 80 100 |
| (예) A | 금요일 | 80 90 100 120 |
| (예) A | 토요일 | 95 105 120 140 |

숙박 최저 요금 / 대실 최고 요금 (이상값 탐지용): (예) 60,000 / 40,000
채널 고정 쿠폰: (예) 채널 B 토요일 1만 원
