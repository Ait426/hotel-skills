# 사용 안내 — staytools-ota-inventory-audit

PMS와 OTA(야놀자·여기어때 등)의 재고·판매상태 대조. 버전 1.3.0.

이 배포본은 특정 숙소의 식별 정보와 고정값을 뺀 범용판입니다. 본문과 양식의 숫자는 형식 예시이며
어느 OTA의 공통 계약 조건도 아닙니다. **자기 숙소의 값을 넣어 쓰세요.**

## 설치

- **Claude (Cowork·채팅)**: 사용자 지정 → 스킬 → 추가 → 스킬 업로드에서 이 ZIP을 선택합니다.
  새 작업에서 `/staytools-ota-inventory-audit` 을 고르거나 "staytools-ota-inventory-audit 스킬로 …"라고 요청합니다.
- **Claude Code**: 압축을 풀어 나온 폴더를 프로젝트의 `.claude/skills/` (또는 `~/.claude/skills/`) 아래에 넣습니다.

## 준비할 입력

- PMS 객실 타입별 잔여(화면 또는 내보낸 표)
- 채널별 상품 × 날짜의 판매상태·잔여·요금
- OTA 상품 ↔ PMS 객실 매핑
- 운영 예외(조식 미운영일, 상시 마감 상품, 오버부킹 허용치)

빠진 값은 스킬이 되묻거나 "미확인"으로 표시합니다. 임의로 채우지 않습니다.

## 들어 있는 파일

- `SKILL.md` — 제1원칙 · 작업 순서 · 자동 수정/확인 기준
- `references/` — 수집 절차(sites) · 판정 규칙(rules) · 요금제 판정(rateplan) · 수정 절차(fix) · 보고 형식(report) · 교훈 로그(lessons)
- `hotel-profile.example.md` — 숙소 프로필 양식

## 범위와 주의

화면 수집과 수정은 브라우저 조작 도구가 있는 환경에서만 됩니다. 도구가 없으면 받은 표로 판정과 조치안까지 작성합니다. 수집·수정 절차는 YFlux PMS, 야놀자·여기어때 모텔 파트너센터 기준입니다.

- 투숙객·고객의 이름·연락처·예약번호는 입력 자료에서 지우고 주세요. 스킬도 결과물에 남기지 않습니다.
- 로그인과 계정 인증은 사용자가 직접 합니다. 비밀번호·인증 토큰을 스킬이나 대화에 넣지 마세요.
- 계산값은 실제 정산 확정액이 아닙니다. 정산서·예약 결제 내역으로 확인하세요.
- OTA 화면과 정책은 바뀔 수 있습니다. 화면 절차가 맞지 않으면 숫자를 믿지 말고 다시 확인하세요.
