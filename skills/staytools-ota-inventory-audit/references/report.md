# 보고 형식

## 채팅 본문 — 짧게

세 줄을 넘기지 마라. 표를 늘어놓지 말고 **무엇이 문제고 얼마를 잃고 있는지** 말로 쓴다.

```
1. (가장 큰 건) — 예: 10월 대실이 31일 통째로 재고 0. 한 달 판매가 막혀 있음
2. (고친 것) — 몇 건을 어떻게 바꿨는지, 어느 채널인지
3. (물어볼 것) — 승인이 필요한 항목
```

## 아티팩트 — 대조판

반복해서 열어볼 운영 문서다. 아티팩트로 발행하고 링크를 준다.
같은 대조판을 계속 쓰는 경우 **같은 URL로 갱신**한다 (`action:"list"`로 기존 URL을 찾아 `url`로 재발행).

담아야 할 것:
- 요약 타일 — 반영 완료 건수 / 보류 건수 / 위험 건수
- 가장 큰 발견을 맨 위 배너로
- 바꾼 내역 목록 (날짜 · 상품 · 채널 · 무엇을)
- 전수 매트릭스 — 행=날짜, 열=상품, 칸은 채널별로 나누고(예: 야놀자/여기어때 두 칸) PMS 잔여를 작은 숫자로. 어긋난 칸은 테두리로 표시
- 읽는 법 주의사항 (매핑은 추정 / 수량은 스냅샷 / 프로필의 운영 예외는 정상)

## 아무 문제도 없을 때

"이상 없음"만 쓰지 말고 **무엇을 몇 개나 봤는지**를 함께 적어라.
예: "8/25~9/23 30일 × 13개 상품 × 2채널 전수 확인, 어긋난 칸 없음. 10월 대실도 재고 정상."

## 자동 실행일 때

매일 아침 자동 실행이면 **문제가 있을 때만 길게 쓴다.** 이상 없으면 한 줄로 끝낸다.
