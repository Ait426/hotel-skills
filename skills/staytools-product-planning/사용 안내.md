# 사용 안내 — staytools-product-planning

제품 아이디어 브레인스토밍 · 가정 검증 (사고 파트너). 버전 1.2.0.

이 배포본에는 특정 숙소나 개인의 정보가 들어 있지 않습니다.

## 설치

- **Claude (Cowork·채팅)**: 사용자 지정 → 스킬 → 추가 → 스킬 업로드에서 이 ZIP을 선택합니다.
  새 작업에서 `/staytools-product-planning` 을 고르거나 "staytools-product-planning 스킬로 …"라고 요청합니다.
- **Claude Code**: 압축을 풀어 나온 폴더를 프로젝트의 `.claude/skills/` (또는 `~/.claude/skills/`) 아래에 넣습니다.

## 준비할 입력

- 다루려는 문제나 아이디어
- 대상 사용자와 지금의 해결 방식
- 이미 알고 있는 근거와 제약

빠진 값은 스킬이 되묻거나 "미확인"으로 표시합니다. 임의로 채우지 않습니다.

## 들어 있는 파일

- `SKILL.md` — 브레인스토밍 모드 · 프레임워크 · 세션 구조 (영문 지침. 대화는 사용자의 언어로 진행됩니다)

## 범위와 주의

대화형 사고 보조 스킬입니다. 시장 수요나 매출을 보장하지 않습니다.

- 투숙객·고객의 이름·연락처·예약번호는 입력 자료에서 지우고 주세요. 스킬도 결과물에 남기지 않습니다.
