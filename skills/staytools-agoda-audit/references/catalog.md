# 아고다 카탈로그 · 설정 가능 범위

**카탈로그 자체는 모든 숙소 공통이다.** 포털 생성/수정 폼을 열어 읽은 구조다 (2026-08 기준).
**폼을 열어서 읽기만 했고 저장 버튼은 누르지 않았다.** 시기·지역에 따라 항목과 범위가 달라질 수 있으니
숫자를 쓰기 전에 그 숙소의 포털에서 다시 읽어라.

`properties/{숙소}-promotions.md` 가 "그 숙소가 만들어둔 인스턴스"라면, 이 문서는 **"아고다가 제공하는 것 전부"** 다.
둘을 섞지 마라. 전자는 숙소의 서랍 속이고, 여기 적힌 게 상점 진열대다.

목차
1. 중복 규칙 (제일 중요)
2. 프로그램 3종 — 수수료·광고비
3. AGX 수수료-순위 곡선
4. 프로모션 카탈로그 3갈래
5. 각 폼에서 정할 수 있는 것
6. 숙소마다 확인할 것

---

## 1. 중복 규칙 — 아고다 포털 원문

객실 점유율 프로모션 생성 폼에 이렇게 적혀 있다:

> "예약이 두 개 이상 프로모션의 적용 대상인 경우, 프로모션이 중복 적용됩니다.
> 이 프로모션은 **알뜰 프로모션, 시즌 프로모션 1개, 그리고 각 타겟팅 프로모션
> 카테고리(예: 플랫폼, 멤버십)별 프로모션 1개**와 함께 중복 적용될 수 있습니다."

마감 임박 프로모션 폼에는 덧셈이라는 게 아고다 문장으로 박혀 있다:

> "기존 판매 중인 20% 프로모션에 본 10% 프로모션 중복 적용 설정을 더하면 **총 할인은 30%**가 됩니다."

시즌 프로모션 폼:

> "이 프로모션은 **시즌 프로모션을 제외한** 기존의 요금 채널 및 프로모션에 중복 적용됩니다."

### 그래서 Σ는 이렇게 센다

```
Σ = Maximum Gain (프로그램. 실제 %는 예약의 프로모션 내역에서 읽는다)
  + 시즌 프로모션 (최대 1개)
  + 타겟팅 프로모션 (카테고리당 1개: 지역 1 + 플랫폼 1 + 멤버십 1 + …)
  + 알뜰 프로모션 (개수 제한 없음, 전부 더해짐)
```

**프로모션 개수를 세지 말고 카테고리를 세라.**

실제 예약으로 이렇게 검증한다 (새 숙소에서도 같은 방식으로 확인해라):
- 시즌 계열을 여러 개 켜 둬도 예약에는 하나만 붙는가 → 시즌 1개 규칙
- 해외 거주 손님 예약에 지역 타겟팅이 하나만 붙는가 (US (IP only) 가 붙으면 International Rate 는 안 붙는다)
  → 둘 다 지역 카테고리
- 예약의 Σ가 "MG + 지역 1 + 알뜰 합 + 시즌 1" 과 정확히 맞는가

위험 지점: **알뜰만 개수 제한이 없다.** 얼리버드 10% + 마감 임박 10% + 장기 투숙 5%를
다 켜면 리드타임이 겹치는 예약에서 25%p가 한꺼번에 빠진다.

## 2. 프로그램 3종

포털 > 비즈니스 성장 프로그램 > 캠페인 > `캠페인 설정하기` 에서 제공되는 것은 3개다.

| 프로그램 | 설정 가능 범위 (관측) | 그 숙소의 현재 설정 |
|---|---|---|
| 아고다 성장 프로그램 (AGP) | 이력상 무료 체험 / 8% / 17% 가 관측됨. 포털에 슬라이더 없음 | `properties/` 에 기록 |
| 아고다 성장 익스프레스 (AGX) | 예약당 **1% ~ 40%**, 1%p 단위 (슬라이더 aria min=1 max=40) | `properties/` 에 기록 |
| 광고 대상 숙소 (Sponsored Listing) | 순위 **Top 3 / Top 15** 2가지. 요율은 견적 화면에서 읽는다 | `properties/` 에 기록 |

**셋 다 "수령 요금에서 차감"을 고를 수 있고, 그러면 전부 보수(수수료)로 들어온다.**
Σ프로모션이 아니라 `(1 − 보수)` 쪽을 깎는다. 셋을 다 켜면
보수 = 계약 수수료 + AGP + AGX + SL 견적 요율이다. 합계를 직접 더해 확인해라.
(단, 콘솔의 `commission.parts` 에는 광고 숙소를 넣지 않는 것이 기본이다 — SKILL.md 참고.)

### AGX 타겟팅 (신규 캠페인 폼)

| 축 | 고를 수 있는 값 |
|---|---|
| 대상 여행객 | 모든 여행객 / 해외 생성 예약 / 아시아 인바운드 / 국내 생성 예약 / 국가 선택 |
| 투숙 기간 | 날짜 범위 또는 전체 |
| 리드 타임 | "N일 미만" 지정 또는 전체 |
| 주중/주말 | 모든 요일 / 주중 / 주말 |

**아고다 기준 주중 = 일·월·화·수·목, 주말 = 금·토.** 숙소의 CMS 요일 구분과 같은지 대조해라.

포털 팁 문구에 **"(도시) 방문 여행객의 N%는 국내 여행객입니다."** 가 뜬다.
이 비율이 높은 시장에서 해외 타겟 캠페인은 노출이 거의 안 나온다. 타겟을 고르기 전에 이 문구부터 읽어라.

고급 옵션 3개: ① 다른 캠페인 중복 적용 ② 크레딧으로 비용 충당
③ **마감 임박 예약 여행객에게 수수료 증가 조정을 2배** — 켜져 있으면 임박 예약의 AGX 수수료가 2배가 된다.

AGX 크레딧 잔액이 있는데 비용 지불 방법이 "수령 요금에서 차감"이면 크레딧이 안 쓰인다. 같이 확인해라.

### Sponsored Listing 상세

- 캠페인 기간: 주 단위 선택. 이미 "마감"이거나 "이용 불가"인 주가 있다
- 대상 검색어: 도시명 / 지역명 복수 선택 (검색 비중이 함께 표시된다)
- 비용 지불: 예약당 차감 / 신용카드 선불 / 은행 송금 선불
- 견적 화면이 Top 3 / Top 15 각각의 **예약당 %, 예상 노출 증가, 예상 예약 증가**를 보여준다.
  → **요율 대비 노출 증가폭을 비교해라.** 요율은 비슷한데 노출 증가가 한 자릿수 %인 옵션은 살 이유가 없다.

## 3. AGX 수수료-순위 곡선 — 숙소마다 직접 읽는다

캠페인 수정 화면에서 슬라이더를 움직이면 % 별 **예상 순위 · 노출 점유율 · 노출 증가**가 바뀐다.
저장하지 않고 읽기만 하면 된다. 아래 형식으로 기록한다.

| AGX % | 예상 순위 | 노출 점유율 | 노출 증가 |
|---|---|---|---|
| 0 (미적용) | | | 기준 |
| 1 | | | |
| 2 | | | |
| … | | | |
| 40 (최대) | | | |

읽는 법:
- **순위가 더 안 오르는 지점이 그 시장의 실효 상한이다.** 그 위는 수수료만 늘고 순위는 그대로다.
- 추가 %p 의 비용을 입금가로 환산해라: `CMS × (1 − Σ) × 추가 %p`.
  예) CMS 180,000 · Σ 55% · 추가 2%p → 180,000 × 0.45 × 0.02 = **한 박 1,620원**.
- 화면에 "유사한 숙소 데이터를 기반으로 한 추정치이며 순위·노출은 보장하지 않습니다"라고
  적혀 있다. 경쟁 숙소가 같이 올리면 곡선이 바뀐다. **AGX 룸나잇 실적이 0이면 실증이 없는 것이다.**
- 경쟁 숙소의 노출 점유율도 같은 화면에 나온다. 숙소명은 보고서에 그대로 옮기지 말고 "경쟁 A/B"로 적는다.

## 4. 프로모션 카탈로그 3갈래

포털 > 프로모션 > `새로운 프로모션 선택하기`. "프로모션 모두 보기"까지 전부 펼쳐서 읽는다.

### 시즌 프로모션 (아고다가 기간을 정해 연다. 목록은 시기마다 바뀐다)

관측 예 (2026-08 시점 목록): Bye-Bye Summertime · Hot Deal · 월간 중순 세일 ·
[Flash Sale] Midnight Madness (자정~새벽3시) · [Flash Sale] Noon Dash Deals (14~18시) ·
올빼미 세일 · Deals Abroad · 미리 예약하고 더 저렴하게 · 3박한 특가 · 깜짝 할인 수요 특가 ·
월급날 세일 · 더블 데이 메가 세일 · Maple Week · Agoda Save & Go ·
할로윈 세일 · 블랙 프라이데이 세일 · 연말 세일 · 크리스마스 세일

**메가세일 판매 기간 사이에 공백이 있으면** 그 기간에 열리는 시즌 프로모션이 대체 후보다.
조사할 때 "지금 열려 있는 것 + 각 예약 가능 기간"을 그대로 옮겨 적어라.

### 알뜰 프로모션 — 5종 (숙소가 직접 만든다. 개수 제한 없음)

| 종류 | 조건 축 |
|---|---|
| 객실 점유율 프로모션 | 체크인 **14일 전** 판매율, 구간 3개까지 — `promotion-rules.md` 6장 주의 |
| 맞춤형 프로모션 | 자유 |
| 마감 임박 프로모션 | 체크인 N일 전 이내 예약 (폼 기본 3일) |
| 장기 투숙 프로모션 | 최소 숙박 수 |
| 얼리버드 프로모션 | 체크인 N일 전 예약 (실제 경계는 예약으로 확인) |

숙소가 종류별로 몇 개를 보유하고 있는지는 `properties/{숙소}-promotions.md` 에 적는다.
**같은 이름이 여러 개 쌓여 있는 경우가 흔하다** (매달 새로 생성된 중복). 할인율이 큰 옛 인스턴스가 섞여 있는지 본다.

### 타겟팅 프로모션

| 카테고리(추정) | 프로모션 |
|---|---|
| 지역 | International Rate · US (IP only) · Asia (IP only) · Domestic · China · GoLocal Tonight |
| 플랫폼 | Mobile · Package |
| 멤버십 | Private Sale · VIP Platinum(2년 10건+) · VIP Gold(5건+) · VIP Silver(2건+) |
| 기타 | Eco Deals (아고다·WWF CSR) |

Domestic은 조심해라. **손님 대부분이 국내인 시장**에서는 사실상 전체 할인과 같다
(AGX 폼의 "국내 여행객 N%" 문구로 판단).

## 5. 각 폼에서 정할 수 있는 것

### 알뜰 프로모션 (마감 임박 폼 실측 — 5종 공통)

- 프로모션명 (자유, 200자, 손님에게 안 보임)
- 조건 일수 (마감 임박은 "사전 예약 필요 최대 일수", 기본 3, min=0)
- 예약 가능 기간 / 투숙 기간 (각각 무기한 연장 체크 가능)
- **할인 유형 4종**: 할인율 % / 무료 숙박 / 1박당 정액 / 예약당 정액
- 할인율 (기본 20%. **포털에 상·하한 표기 없음**)
- 중복 할인 켜기/끄기 (기본 켜짐)
- 고급 설정:
  - 최소 객실수
  - **할인 적용 대상: 총 투숙 기간 / 특정 투숙일 / 특정 요일 / 투숙 첫날 / 체크아웃 전날**
  - 최소·최대 숙박 수
  - **예약 가능 요일** (월~일 개별)
  - **체크인 가능 요일** (월~일 개별)
  - 예약 가능 시간 시작·종료 (숙소 시간, 24시간 형식)
  - 외부 참조 ID (채널 매니저용)
- 제한사항: 적용 제외 기간 (여러 개 추가 가능)

**잘 안 쓰이지만 유용한 것 둘:**

1. **"할인 적용 = 투숙 첫날 / 체크아웃 전날 / 특정 요일"** — 3박 예약에서 하루만 할인할 수 있다.
   Σ가 전체 박수에 안 걸리니 입금가 타격이 1/3로 준다.
2. **"체크인 가능 요일"** — 특정 요일 체크인만 골라 할인할 수 있다.
   운영자가 직접 관리하는 요일을 CMS를 안 건드리고 조절하는 방법이다.
   단 그 요일 요금이 사전 합의 대상이면 제안만 하고 켜지 마라.

### 시즌 프로모션 (폼 실측)

- 프로모션명 (참조용)
- **할인율 % 직접 입력** (기본 15%). 아고다가 고정하는 게 아니다
- 예약/투숙 기간: 아고다가 준 기간 세트를 선택·해제만 가능. 숙소가 늘릴 수 없다
- 프로모션 제외 기간
- 최소 객실수 / 최소 숙박 수
- 예약 가능 요일 / 체크인 가능 요일 / **투숙 가능 요일** (각각 월~일)
- **객실 종류** 중 선택 / 전체 / 전체에서 일부 제외
- 중복: 끌 수 없음. 시즌끼리는 자동으로 1개만

### 타겟팅 프로모션 (Mobile 폼 실측)

- 할인율 % 하나 (기본 10%)
- 기간 설정란 없음 — 켜면 무기한
- 중복 스위치 없음 — 항상 중복 (같은 카테고리끼린 1개)
- **요금제 선택**: 숙소의 요금제 목록에서
  - 모두 적용 / 선택한 항목에만 적용
  - 'Beds Network Payout'과 '체인 도매(Chain Wholesale)' 요금제는 기본 제외

**타겟팅 프로모션은 요금제별로 켜고 끌 수 있다.** 요금제마다 Σ를 다르게 줄 수 있다는 뜻이다 —
요금제 간 노출가가 어긋나는 원인이 여기일 수 있다.

### 객실 점유율 프로모션 (주의 대상이지만 구조는 알아둘 것)

- 판매율 구간 3개 (각 범위 ~ 범위, 할인 %)
- 요일 선택 (7개 개별)
- **"객실 판매 확인 = 14일"** — 체크인 14일 전 판매율로 판정한다
- 설정값과 실제 예약에 붙은 값이 달랐던 사례가 있다 (설정 5% → 실제 10%).
  **이 프로모션은 설정 화면만 보고 신뢰하지 마라.** 켰다면 첫 예약의 프로모션 내역을 반드시 확인한다.

## 6. 숙소마다 확인할 것

추정으로 채우지 마라. 확인 못 했으면 `open[]` 에 옮겨 적는다.

| 항목 | 왜 필요한가 | 어디서 |
|---|---|---|
| 프로모션 할인율 상·하한 | 사고 방지선을 못 긋는다 | 생성 폼에 값 입력 후 검증 메시지 (저장은 사용자가) |
| AGP 요율 전환 조건 | 보수에서 차지하는 비중이 크다 | 아고다 담당 매니저 / 인텔리전스 프로그램 |
| AGX 고급 옵션 3개의 실제 on/off | "마감 임박 수수료 2배"가 켜져 있으면 임박 예약 보수가 오른다 | AGX 캠페인 수정 화면 하단 |
| 아고다 인텔리전스 수수료 할인율 | 보수를 낮추는 유일한 경로 | 비즈니스 성장 프로그램 |
| 부킹홀딩스 광고 CPC 단가 | 광고비 갈래 단가 | 비즈니스 성장 프로그램 |
| 타겟팅 카테고리의 정확한 구분 | '지역'이 하나인지 IP/국가로 나뉘는지 | 같은 카테고리 후보를 켰을 때 예약 프로모션 내역 변화 관측 |
| 프로그램 변경 전후의 실제 보수 | 개시·삭제 시점 전후 투숙분의 보수가 다르다 | 해당 기간 정산서 |
| 할인 시뮬레이터 | 아고다 제공 도구. Σ 덧셈 확인용 | 프로모션 > 새로운 프로모션 선택하기 우측 상단 |

## 부록 — 캠페인 이력 읽는 법 (포털 적용 만료 / 삭제됨 탭)

| 캠페인 | 비용(%) | 종료·삭제일 | 노출 | 순위 | 룸나잇 | 수익 |
